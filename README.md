# impala-admin-toolkit
Impala administration: query profiling, catalog refresh, memory management.

## Scripts
| Script | Purpose |
|--------|---------|
| `scripts/impala_queries.py` | Monitor running and recent queries via Impala API |
| `scripts/impala_catalog.sh` | Refresh/invalidate Impala catalog metadata |
| `scripts/impala_mem_check.sh` | Check memory usage per Impala daemon |
| `scripts/impala_stats.sh` | Compute Impala table statistics |
